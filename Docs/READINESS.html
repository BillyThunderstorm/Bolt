How you actually run it

Canonical entry: bin/bolt (uv sync, then uv run bolt …).

cd /Users/carter/developer/Bolt
uv sync
bolt setup          # Core/launch.py — finite, must exit
bolt verify / bolt doctor
bolt recordings     # → Core/bot.py pipeline
bolt day --decide   # queue review
bolt launch         # folder-watch + optional OBS
bolt queue decide
bolt morning / manage / research / mission / voice / budget / overlay

Live clip path: Highlight_Detector → Clip_Generator → Clip_Deduplicator → Title_Generator → (subtitles: pass) → Clip_Ranker → Clip_Factory → Post_Queue / Peak_Hour_Notifier.

Not real launchers for a stranger: python3 Core/src/launch.py (empty), App/app.py (stale path), App/BoltApp (Base44 todo app), bolt-creator-command-center/ (redirect only).

If someone else used this tomorrow

What works

  • After uv sync + .env, bolt recordings / bolt launch on local video: detect, cut, rank, 9:16, enqueue.
  • bolt queue decide is the real posting OS (manual upload + mark-posted).
  • manage / research / mission / day / morning / briefing are real local JSON/markdown tools.
  • doctor / verify / test will tell them what’s missing.
  • With Ollama (llama3.1:8b + nomic-embed-text), Nexus/titles get smarter. Without it, templates still cut clips.

What will disappoint

  • README “titles, subtitles, ranked queues” — subtitles are a no-op.
  • TikTok auto-post / M11 — API paused.
  • Creator Command Center / BoltApp — Base44 todo template.
  • Dashboard (JS, no HTML) and menu bar app (wrong paths, missing rumps).
  • OCR “KILL STREAK” titles, anomaly/predictive, skincare/tech analyzers look shipped; they are not wired.
  • PROJECT_STATUS oversells M1–M13, Discord, ElevenLabs. Voice default is macOS Voice 3.

Top 5 that look like features but aren’t

  1. Subtitles in the clip pipeline — advertised; bot.py Step D is pass.
  2. TikTok auto-publish — real client, hard-paused.
  3. OCR data-driven titles — Video_Intelligence exists; bot.py never calls extract_stats().
  4. Anomaly detection + view forecasting — tested modules, zero pipeline callers.
  5. Checkup dashboard / macOS app / App/BoltApp — claimed UIs that aren’t Bolt.

Stranger-ready subset: CLI + local clip factory + queue review + catalog/research/mission markdown. Everything that needs cloud APIs, TikTok app review, OBS, or a GUI is gated, paused, or a shell.
