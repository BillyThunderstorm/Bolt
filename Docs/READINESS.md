## How you actually run it

Canonical entry: `bin/bolt` (`uv sync`, then `uv run bolt …` or the venv shim).

```bash
cd /Users/carter/developer/Bolt
uv sync
bolt setup          # Core/launch.py — finite, must exit
bolt verify / bolt doctor
bolt recordings     # scripts/process_recordings.py → Core/bot.py
bolt day --decide   # Core/bolt_day.py → queue review
bolt launch         # Core/launch.py → exec Core/bot.py
bolt queue decide   # Peak_Hour_Notifier
bolt morning / manage / store / research / mission / voice / budget / overlay / analytics / anomaly / predict / enhance / checkup / ocr / amazon / menubar / search / word / youtube-pkg / x-pkg / multi / tiktok-post / gemini / nexus / obs / streamlabs / chat / brain / vods / stats / sites / storage / drive / discord / merge-py / titles / learning / domains / pages / license / mac-app / mac-auto / alerts / checklist / reminders / photo-ocr / compress / performance / weekly / filter-backlog / make-highlights / reprocess / health / layout / migrate-layout / log-perf / watch / refresh-memory / memory / calendar / send / icloud / game-config / error-recovery / memsearch / obs-game
```

Live clip path: `launch.py` → `bot.py.process_recording`: Highlight_Detector → Clip_Generator → Clip_Deduplicator → (optional Skincare_Analyzer / AI_Analyzer / Amazon_Analyzer when `content_type` is skincare|tech|review) → Title_Generator → Subtitle_Generator → Clip_Ranker → Clip_Factory → Post_Queue / Peak_Hour_Notifier.

Prefer `bolt launch` / `bolt setup` (canonical). `Core/src/launch.py` is a real compat forwarder to `Core/launch.py` (legacy path OK). Menu bar is real via `bolt menubar` (rumps; not a shipping Mac/iOS `.app` bundle).
