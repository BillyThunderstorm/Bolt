WEEK OF: _____________   LANE FOCUS THIS WEEK: _______________________

───────────────────────────────────────────────────────────────────────────
  BEFORE YOU START (Sunday evening, 30 minutes)
───────────────────────────────────────────────────────────────────────────

  □  Pick which lane gets the heaviest focus this week
     (rotate so each of the 4 lanes gets ~25% over a 4-week cycle)

  □  Pick the ONE hardest task for this week
     (C4: harder first; finish it before touching anything else)

  □  List the 3-5 secondary tasks for the week

  □  Identify the 1-2 things only YOU can do
     (Bolt can do the rest, but it needs approval)

───────────────────────────────────────────────────────────────────────────
  DAILY SESSION STRUCTURE
───────────────────────────────────────────────────────────────────────────

  Each session = burst, max 8 hours, with breaks.

  Session start:
    □  HARDEST TASK FIRST — finish completely before moving on
    □  Check Apple Reminders for today's briefing
    □  Note lane focus for today's session

  Session middle:
    □  Hard task complete?
       □ YES → move to secondary task
       □ NO  → keep working on hard task until done

  Session end:
    □  ALL tasks in this session complete? (no half-done tasks)
    □  Note anything Bolt should follow up on
    □  Close any reminders you actioned today

───────────────────────────────────────────────────────────────────────────
  C1-C7 GATES — apply to EVERYTHING before you do it
───────────────────────────────────────────────────────────────────────────

  Before posting anything, asking for any sponsor deal, or committing
  to any lane direction, run it through these tests:

  □  C1: Would this sell a hyped dud as if it works? → if yes, don't
      (honest review of a dud you own + a working alternative is OK)
  □  C2: Do I know this is the right direction?       → if no, pause
  □  C3: Does this add to my roadmap for someone else? → if no, skip
  □  C5: Would I want to be known for this?            → if no, don't
  □  C6: Do I believe in / stand behind / trust this?  → if no, NO
  □  C7: Is this Trump/MAGA-adjacent or insulting?     → if yes, NO

───────────────────────────────────────────────────────────────────────────
  LANE ROTATION — even split across the month
───────────────────────────────────────────────────────────────────────────

  Week 1: □ Gaming + pop culture (superheroes, film/TV)
  Week 2: □ Tech gadgets + AI development
  Week 3: □ General product testing
  Week 4: □ Skincare + personal advice

  Repeat. Each lane gets a focused week, then continues with smaller
  effort the rest of the month. Over 4 weeks = 25/25/25/25.

  □  Lane rotation: which lane gets next week?
  □  Any sponsor outreach in flight?
  □  Any C6 violations I caught myself on?
  □  Anything Bolt should know for next week?
