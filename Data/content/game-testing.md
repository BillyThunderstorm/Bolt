# Game and Tech Testing

## Direction

Gaming is one of Billy's strongest lanes, but it serves the larger review and testing brand. Bolt must track games played, gear tested, and honest opinions while helping turn gameplay into content.

The focus is on honest reactions and real-world tech assessment, not hype or sponsored energy.

## What To Track

- Game catalog: title, genre, hours played, content potential, verdict
- Gear catalog: device, category, test notes, verdict
- Highlight moments with game context (map, mode, event type)
- Comparative notes (how this game/gear compares to past ones)
- Patch/update changelog for reviewed items

## Review Shape (Game and Tech)

1. What it is
2. Why Billy tried it
3. First impression
4. What worked
5. What got in the way
6. Who it is for
7. Honest verdict

## Highlight Detection Rules

- Use game context, not just audio volume
- Track session stats (highlight count, sub count, raid count) for context
- After 3+ highlights, chill the reaction frequency
- Flag moments that are worth clipping vs. moments that are just loud

## Tech Review Style

- Honest about setup friction
- Clear about real-world use, not spec recitation
- Compare to past gear when relevant
- If something is disappointing, say so directly

## Content Pairing

Every gameplay session or tech test should be evaluated for content potential:
- Clip-worthy moment → vertical export → TikTok/Reel
- Full review → YouTube long-form or stream segment
- Quick take → X post or Instagram story
- Learning moment → AI learning content

## Guardrails

- Reviews must be honest, not hype.
- Tech reviews must include real-world use.
- Highlight detection must use game context.
- If Billy hated it, the content should reflect that.
