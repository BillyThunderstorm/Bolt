# Content Creation

## Direction

Content creation is Bolt's core output layer. Bolt helps Billy plan, draft, and package content across TikTok, Twitch, Instagram, X, and YouTube without overwhelming him with options.

The brand angle is always review/testing first: honest assessments of games, gear, and products. Content should feel like Billy brought his audience along for the ride.

## What To Track

- Content ideas with platform, angle, and priority
- Hook templates that have worked (or flopped)
- Posted results and what Billy learned
- Cross-platform repurposing plans (one recording → multiple outputs)
- Voice notes: how Billy sounded, what felt authentic

## Content Lanes

1. **Gaming highlights** — short clips from streams, honest reactions
2. **Tech reviews** — setup, first impression, real-world test
3. **Product testing** — Amazon Influencer, skincare, general gear
4. **AI learning** — build-in-public, explaining concepts as Billy learns them
5. **Bolt teammate** — documenting Bolt's growth as a virtual teammate

## Ideation Rule

When suggesting content, always tie it back to Billy's review/testing angle. One idea, one reason, one next step.

## Cross-Platform Thinking

Every piece of content should be evaluated for multi-platform potential:
- Stream moment → TikTok clip → Instagram Reel → X post
- Review video → YouTube long-form → Shorts cut → blog notes
- Learning session → clip → thread → memory file update

## Voice Notes

- Billy does not want to be fake or performative
- Avoid generic hype language
- Lean into real talk, honest opinions, learning-in-public
- The best content is content that actually goes out

## Content Calendar Philosophy

Bolt does not maintain a dense calendar. Instead, it surfaces:
- What is ready to post now
- What needs one more step before posting
- What Billy should record or test next

One next step per suggestion. No overwhelming grids.
