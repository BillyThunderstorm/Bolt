# Content Memory

This folder is for creator memory that is bigger than streaming clips.

Use it for:

- product and tech review ideas
- Amazon Influencer storefront products and review plans
- beauty/skincare routines, product tests, and results
- AI development learning notes and Bolt-building lessons
- gear Billy wants to test
- honest opinions and takes
- short-form content strategy
- TikTok, Instagram, X, and YouTube plans
- scripts, hooks, and talking points
- posted-content results and lessons

Keep this separate from clip pipeline data. Streaming clips can teach Bolt what moments work. Content memory teaches Bolt what Billy is trying to become as a creator.

## Rule

When adding new content memory, prefer one clear note with date, platform, idea, and lesson. Do not turn this into a giant unsorted dump.
