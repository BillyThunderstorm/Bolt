# Daily Briefing Memory

Bolt should eventually be able to prepare a useful morning briefing for Billy.

The original Desktop `Content_Ideas.md` file described this as a 6 AM briefing covering calendar, inbox, Bolt project context, and content creation priorities. The durable template now lives at `docs/daily-briefing-template.md`.

## Purpose

Help Billy start the day with a clear view of:

- calendar blocks
- important emails
- Bolt project priorities
- content work
- product testing or Amazon storefront opportunities
- beauty/skincare testing reminders
- AI learning or upgrade focus

## Rule

Do not turn the briefing into a giant dashboard. It should identify what matters, explain why it matters, and give a small number of concrete actions.

## Content Angle

This is also content: Billy is building a virtual teammate that can help keep the whole creator vision organized instead of letting one lane erase the others.
